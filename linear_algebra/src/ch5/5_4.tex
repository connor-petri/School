\subsection*{Rank of a Matrix}
\paragraph*{Definition}
The \textit{rank} of a matrix $A$, denoted $\mathrm{rank}(A)$, is the maximum number of linearly independent rows or columns in $A$.
Previously we have seen that the rank of a matrix is equal to the number of pivots in its row echelon form, which is also equal to the number of nonzero rows in its reduced row echelon form. 
The rank of a matrix can also be defined as the dimension of the column space or the row space of the matrix.

\paragraph*{Definition}
The \emph{column space} of a matrix $A$, denoted $\mathrm{Col}(A) = \text{span}\{\vec{a}_1, \vec{a}_2, \ldots, \vec{a}_n\} = \text{Im}(A)$, is the set of all linear combinations of the columns of $A$. 
The column space is a subspace of $\mathbb{R}^n$ if $A$ is an $m \times n$ matrix.

The \emph{row space} of a matrix $A$, denoted $\mathrm{Row}(A)$, is the set of all linear combinations of the rows of $A$.
The row space is a subspace of $\mathbb{R}^m$ if $A$ is an $m \times n$ matrix.
