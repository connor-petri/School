## What are Computer Graphics?
Computer graphics are pictures and films created using computers.
> Scene description -> Rendering -> Image

Digital imagery in still image, animated, or real-time form created on a device with a display such as a:
- Computer with Monitor
- Laptop
- Mobile device
- Game Console
- Kiosk
- Theatrical Display
- VR Display

### Where are computer graphics used?
- Feature Animation
- Live Action / Visual Effect
- Virtual Production
    - Motion Capture
    - Virtual Reality
- Video Games
    - Unreal
    - Unity
    - Godot
- Compositing
    - In 2D compositing, elements are removed from their original backgrounds and combined with other elements to create a new image.
- Product Design
    - Car configurators, etc.
- Architecure Visualization

### Why Rust?
- Safe Language (avoids memory and pointer bugs)
- Cargo package manager
- Compiled - If program compiles it has a good chance of running
- Good editors
